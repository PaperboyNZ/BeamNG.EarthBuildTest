# Bundled sign typefaces and shaping

This bundle contains 214 font binaries, including regular faces from all 176 Noto Sans script-family directories in the pinned Noto source, a Noto Serif Tibetan face, four regional CJK fonts, additional Noto weights, four Latin display families, and Amiri for mixed Arabic and Latin text. `manifest.json` records the source and SHA-256 of every bundled font; `FONT-NOTICES.txt` transcribes embedded copyright and license metadata. The full notices are included alongside it. The resolver considers the full script-family inventory and prioritizes dedicated script faces. Explicit `noto_serif`, `arabic_naskh`, and `arabic_kufi` roles and `_bold`, `_italic`, and `_bold_italic` variants are available when files exist. A directory tenant may set `typography_role` explicitly; otherwise it uses `clinical`. Business labels are not classified from their names or assigned cultural styles at random. Font and whole-line resolution caches are bounded. Variable display font weights are Libre Franklin 600, Oswald 600, and Lora 500 for legibility; these settings participate in texture revision hashes.

The sign renderer uses the included fonts offline; it never downloads fonts at tile generation time. The Noto Sans and Serif families are unmodified official SIL OFL 1.1 files. Their embedded name tables include their copyright notices. Additional Noto Devanagari, Bengali and Thai fonts came from https://github.com/notofonts/noto-fonts/tree/main/hinted/ttf, and the CJK regional variants from https://github.com/notofonts/noto-cjk/tree/main/Sans/OTF. Their licenses are in OFL.txt and OFL-CJK.txt. Noto Sans CJK is large because each regional file contains multiple writing systems. Names containing only Han characters use Simplified Chinese forms by default; pass an explicit locale (ja, ko, zh-Hans, zh-Hant) when the source supplies one.

Barlow Condensed, Oswald, Lora, Libre Franklin and Amiri were obtained from their family directories at https://github.com/google/fonts/tree/main/ofl; each has its own OFL notice here. Sign role selects a Latin design while script-aware coverage selects a compatible fallback for an entire line. Coverage and shaping are not guaranteed for every language, Unicode character, script combination, or emoji; a single available font must cover a whole line. Unsupported text is omitted with a diagnostic, never replaced by invented names. Mongolian requires vertical layout and is deliberately left unlabelled by the current horizontal sign renderer. RAQM is required for all non-ASCII text.

On 64-bit Windows, libfribidi-0.dll is the unmodified MSYS2 mingw64 FriBidi 1.0.18-1 build, dynamically loaded before Pillow starts. Its source and rebuild recipe are https://github.com/msys2/MINGW-packages/tree/master/mingw-w64-fribidi; the official package and source archive are https://mirror.msys2.org/mingw/mingw64/mingw-w64-x86_64-fribidi-1.0.18-1-any.pkg.tar.zst and https://mirror.msys2.org/mingw/sources/mingw-w64-fribidi-1.0.18-1.src.tar.zst. The downloaded binary package SHA-256 was 0855a60a2060e2d07d71531839fcd05ef75043c93b8feeede2087533c5bc9b64. FriBidi is LGPL-2.1-or-later; see LGPL-fribidi.txt. Users can replace the dynamic library. Pillow wheels contain RAQM/HarfBuzz and dynamically use FriBidi. On other platforms, provide Pillow built with RAQM and the platform FriBidi library. Where shaping is unavailable, complex text is omitted with a diagnostic. See https://pillow.readthedocs.io/en/stable/installation/building-from-source.html.
