# House variety playtest — schema 19

Build: `BeamNG.Earth-v2-house-variety-20261101`.

Close the existing Earth server and exit BeamNG. Run the parent
`Play latest buildings.bat`, then open BeamNG and select BeamNG.Earth.
Starting another server while the old one owns port 47613 will fail.

This includes the schema 18 city, regional, site and adaptive-streaming work,
plus a stable 70% regional / 20% contemporary / 10% other-global-style house mix.
There are five shared contemporary families, with the earlier suburban mix
included. House fallback paint and roof palettes are broader. Sampled/mapped
colours retain precedence. Experimental facade baking remains disabled.
This package layers house variety onto the verified schema 18 checkpoint;
concurrent driveway/roadside development remains in the editable source and
is excluded from this package pending its own validation.

Revisit Marbeth Court near -36.91410, 174.90925 and compare the supplied earlier
screenshots. Check roof colours, brick/render/timber variety, entrances, road
clearance and stable appearance after travelling away and returning. Inspect
several other regions and day/night, near/far and fast-driving transitions.
Individual streets need not match the proportions exactly.

For performance comparisons, use the same route and graphics settings. Begin
with Adaptive / 350 m, compare Full, and record first approach versus warm
revisit separately. Existing full buildings are retained when selecting Light;
restart or visit an unseen area for that comparison. See SCHEMA18_PLAYTEST.md
for the longer performance checklist and HOUSE_STYLE_MIX.md for implementation
scope and the Auckland roof-colour audit.

Source/package hashes, regression results, geometry parity and offline startup
verification are in the parent artifacts/BeamNG.Earth-v2-house-variety-20261101-verification.json.
Native appearance, driving and frame-time acceptance remain pending.
